تحديث الأرقام لاحقاً
--------------------
لا تُعاد كل الملفات. ملف واحد فقط:

١) افتح:  https://ara2026fat.github.io/daleel/?edit
٢) الإعدادات ← معلومات ← لوحة القائمين
٣) عدِّل أو أضف أو ابنِ منطقة جديدة
٤) تبويب «تصدير» ← تصدير نسخة محدَّثة  (ينزّل ملف JSON)
٥) غيّر اسمه إلى:  daleel-data.json
٦) ارفعه إلى المستودع فوق القديم

من فتح التطبيق يرى شريط «وصل تحديث للدليل».

لوحة التحكم — أربعة تبويبات
---------------------------
  السجلات ..... بحث بالاسم أو الرقم، ثم تعديل أو حذف
  بناء منطقة .. منطقة ← مدينة ← دعاة، بخطوات
                الجنسية تُشتق من اللغة تلقائياً
  استيراد ..... ملف JSON من قائم آخر أو ملصق جديد
  تصدير ....... ينزّل البيانات المحدَّثة

قواعد الدمج في الاستيراد (لا تخمين)
-----------------------------------
· المطابقة بالرقم لا بالاسم.
· رقم غير موجود ← يُضاف سجلاً جديداً.
· رقم موجود باسم مطابق ← تُضاف لغاته وجهاته ولا شيء يُستبدل.
· رقم موجود باسم مختلف ← الاسم القائم يبقى، والوارد يُحفظ في
  «ورد أيضاً باسم» ويوسَم السجل بتنبيه ليراجعه الإخوة.
· رقم غير صالح أو لغة مجهولة ← يُرفض ويُحسب في التقرير.

صيغة ملف الاستيراد:
  {"D":[{"n":"الاسم","p":"05XXXXXXXX","l":["ur","hi"],"o":["الجهة"]}]}
